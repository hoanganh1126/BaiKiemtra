# Test nhanh Bài 3

1. Resize: phóng to cửa sổ, bên trái khoảng 35%, bên phải khoảng 65%.
2. Để trống Tên SP, nhập Đơn giá -50000 -> ErrorProvider, không thêm.
3. Nhập Laptop / Dell / 25000000 / 5 -> bảng hiển thị 25,000,000.
4. Chọn ảnh PNG -> ảnh hiện trong PictureBox kiểu Zoom.
5. Chọn một dòng -> dữ liệu nạp về form; bấm Xóa -> Yes để xóa.
6. Nhập vào ô tìm kiếm -> danh sách lọc theo Tên SP.
7. File -> Export CSV hoặc Ctrl+E -> lưu CSV.
8. Ctrl+X -> thoát chương trình.
