# Bài 3 - TechMart Product Manager

## Chạy
1. Mở `TechMartProductManager.sln` bằng Visual Studio 2022.
2. Nếu hỏi Trust project, chọn `Trust and Continue`.
3. Chuột phải project `TechMartProductManager` -> `Set as Startup Project` nếu cần.
4. Nhấn `Ctrl + Shift + B` để Build.
5. Không có lỗi thì nhấn `Ctrl + F5` hoặc F5.

## Chức năng
- Giao diện TableLayoutPanel 35% / 65%.
- Nhập mã, tên, đơn giá, số lượng, danh mục.
- Chọn ảnh JPG/JPEG/PNG/BMP/GIF và PictureBox Zoom.
- BindingSource + BindingList<Product>.
- DataGridView cột tùy chỉnh, đơn giá N0.
- Chọn dòng để nạp dữ liệu về form.
- Thêm, cập nhật, xóa có xác nhận.
- Tìm kiếm trực tiếp theo tên.
- File -> Export CSV (Ctrl+E), Exit (Ctrl+X).
- StatusStrip tổng số sản phẩm.
